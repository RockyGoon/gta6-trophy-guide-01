## Before you start

Save plan: 15 manual save slots + 1 autosave. 10 slots for chapter start/end (5 chapters × 2), 1 untouched slot from just before the final mission, 4 rotating slots for free-roam cleanup. Cheats off — cheats disable trophies and saving. The 1 missable is id 28 Positive Mental Attitude: do the Chapter 1 balcony meditation before Chapter 1 ends and keep a Chapter 1 save until it pops. No mission replay, no New Game+.

## What is in here

Checklist — every trophy as a card: grade, PSN value, stage and order, kind, missable/watch flag, target count, numbered steps each citing a source by number (272 steps, 327 claims cited, all 272 steps backed by 2+ sources), an audit strip, and a save note; filters by kind, grade, stage, text search, spoiler hiding (17 story trophies) and unearned-only; export and import progress as JSON. Start with Before you start; follow the roadmap stages in order; use the checklist filters and the missable banner; check a trophy's audit strip when sources disagree; use the matrix to see which source backs each step; use the Counts view to track the 15 ledger counters; export your progress regularly.
